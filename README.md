# Amazon Products Ratings & Review Dashboard

## Overview

This project presents an interactive Power BI dashboard designed to analyze Amazon product ratings, reviews, pricing, and discount trends across multiple product categories. The dashboard provides actionable insights into customer satisfaction, product performance, and pricing strategies through data visualization and business intelligence techniques.

## Project Objectives

* Analyze customer ratings and review patterns across product categories.
* Compare actual prices with discounted prices.
* Identify highly rated and heavily discounted categories.
* Generate insights that support business and marketing decisions.
* Visualize customer sentiment and pricing trends effectively.

## Dataset

The project uses an Amazon Product Review and Pricing dataset containing:

* Product ID
* Product Name
* Category
* Average Rating
* Review Count
* Actual Price
* Discounted Price
* Discount Percentage

## Dashboard Features

### Key Performance Indicators (KPIs)

* Average Actual Price
* Average Discounted Price
* Average Product Rating
* Total Number of Categories

### Visualizations

* Actual Price by Category
* Discounted Price by Category
* Discount Percentage by Category
* Actual Price vs Discounted Price Comparison
* Rating Distribution by Category
* Product Distribution by Category
* Average Discounted Price by Category
* Average Rating Count by Category

## Tools & Technologies

* Power BI
* DAX (Data Analysis Expressions)
* Power Query
* Microsoft Excel / CSV Dataset

## Implementation Process

1. Imported the dataset into Power BI.
2. Performed data cleaning and transformation.
3. Created DAX measures for pricing and rating analysis.
4. Designed interactive visualizations and KPI cards.
5. Added filters and slicers for dynamic analysis.
6. Applied dashboard formatting and visual enhancements.

## Business Insights

The dashboard helps:

* Identify high-performing product categories.
* Detect categories requiring improvement.
* Analyze customer sentiment through ratings and reviews.
* Evaluate pricing and discount effectiveness.
* Support data-driven marketing and sales strategies.

## Project Outcome

The dashboard provides a comprehensive view of Amazon product performance by combining customer feedback and pricing analytics. It enables stakeholders to make informed decisions regarding product promotion, pricing strategies, and customer experience improvements.
